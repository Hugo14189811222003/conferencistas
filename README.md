# 📧 Configuración de Resend

Este proyecto utiliza **Resend** para enviar correos electrónicos, por ejemplo para la recuperación de contraseña.

⚠️ **IMPORTANTE:**  
Cada persona que quiera probar el proyecto debe crear su propia cuenta en Resend y usar su propia API Key.
No funcionara si utilizan el mio ya que por seguridad, resend te permite hacer pruebas con el correo con la cual estas dado de alta en su plataforma.
